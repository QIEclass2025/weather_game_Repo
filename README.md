# 🌤️ 날씨 온도 맞추기 게임

실시간/과거 기상 데이터를 기반으로 전 세계 주요 도시의 온도를 맞춰보는 업다운 게임입니다.

## 🎮 주요 기능 요약

- 실시간 날씨 API 연동 (Open-Meteo)
- 도시 수 확장: 서울, 부산, 뉴욕, 런던, 도쿄, 파리, 시드니 외 베를린·싱가포르·모스크바 추가
- 현재 또는 과거 특정 날짜(일별 평균 온도) 모드 선택 가능
- 난이도 선택: 쉬움(±3°C), 보통(±1°C), 어려움(정확히 일치)
- 힌트 시스템 제공 (온도 범위 기반)
- 점수 시스템: 시도 횟수에 따른 점수 부여, 연속 정답(콤보) 보너스
- 페널티: 틀릴 때마다 소량 감점, 시도 초과 시 추가 페널티
- 자동 도시 변경: 정답을 맞추면 다른 도시로 자동 이동하여 게임 계속
- 조언(Advice Slip): 한 도시당 1회만 사용 가능 (도시 변경 시 재사용 가능)

## 📋 요구사항

- Python 3.6 이상
- 필요한 패키지:
  - `tkinter` (GUI, 보통 Python 표준 라이브러리에 포함)
  - `requests` (API 통신)

## ⚙️ 설치 방법

1. 저장소를 클론합니다:
   ```bash
   git clone https://github.com/QIEclass2025/weather_game_Repo.git
   ```
2. uv 패키지 매니저를 이용해 실행합니다:
   ```
   uv run weather_game.py
   ```

## ▶️ 게임 실행 방법

1. `weather_game.py` 파일을 실행합니다.
2. 게임 설정에서 난이도(쉬움/보통/어려움)와 모드(현재/과거)를 선택합니다.
   - 과거 모드를 선택하면 `YYYY-MM-DD` 형식으로 날짜를 입력하세요. (해당 날짜의 일별 평균 온도 사용)
3. 드롭다운에서 시작할 도시를 선택합니다.
4. `🎮 게임 시작` 버튼을 클릭합니다.
5. 입력창에 예상 온도를 소수점 첫째 자리까지 입력(예: `23.5`)하고 Enter 또는 `🎯 온도 맞추기` 클릭.
6. 힌트와 점수를 확인하며 정답을 맞혀보세요.

### ⛔ 그만두기 (게임 중단)

- 게임 도중 `⛔ 그만두기` 버튼을 누르면 현재 게임을 즉시 중단하고 드롭다운에서 다른 도시를 선택할 수 있습니다.
- 중단 시 동작 요약:
   - 현재 시도 횟수는 0으로 초기화되어 다음 게임을 새로 시작할 수 있습니다.
   - `🎯 온도 맞추기` 버튼은 비활성화되고 `🎮 게임 시작` 버튼이 활성화됩니다.
   - 점수와 콤보는 기본적으로 유지됩니다(원하면 중단 시 리셋하도록 변경 가능합니다).
   - 조언 사용 설정과 조언 수신 여부에 따라 `💡 조언 받기` 버튼 상태가 갱신됩니다.


## 🧾 점수 및 콤보 규칙 (요약)

- 정답 획득 시 기본 점수 = max(10, 100 - (시도횟수-1)*10)
- 콤보 보너스: 연속 정답 1회당 20% 추가 곱수 적용 (예: 콤보 2 → x1.4)
- 틀릴 때마다 기본 5점 감점 (최저 0)
- 시도 초과(10회) 시 추가 20점 감점 및 콤보 리셋

※ 위 규칙은 게임 내에서 보정될 수 있습니다. 더 세부적인 산식 조정을 원하시면 알려주세요.

## 💡 조언 받기

- `💡 조언 받기` 버튼을 클릭하면 랜덤 영어 조언을 가져옵니다.
- 한 도시에서 한번 사용하면 버튼이 비활성화됩니다. (자동으로 다음 도시로 넘어가면 재활성화)
 
### 조언 사용 토글

- 설정(⚙️ 게임 설정)에서 `조언 사용` 체크박스를 통해 조언 기능을 켜거나 끌 수 있습니다.
- 기본값은 **켜짐**이며, 체크를 해제하면 `💡 조언 받기` 버튼이 즉시 비활성화되어 조언 호출이 차단됩니다.
- 체크박스를 다시 켜면 현재 도시에서 아직 조언을 받지 않은 경우 버튼이 활성화됩니다. 이미 해당 도시에서 조언을 받았다면, 다음 도시로 이동할 때까지 버튼은 비활성화 상태로 유지됩니다.

이 설정은 플레이어가 조언 기능을 원치 않을 때 쉽게 끌 수 있도록 도와줍니다.

## 🛠️ 과거 데이터(히스토리) 안내

- 사용 시 날짜 형식(`YYYY-MM-DD`)을 정확히 입력해 주세요.
